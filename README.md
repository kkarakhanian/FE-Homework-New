
Зробіть інтерактивний список завдань (to-do list) з такими умовами:

    На сторінці є поле вводу і кнопка "Add".

    Кожен новий елемент списку рендериться в DOM як <li> з текстом і кнопками:

    "Done" — змінює стан елемента (перекреслює текст + додає клас "completed").

"Delete" — видаляє елемент зі списку.

    Додайте лічильник, який показує кількість виконаних і невиконаних завдань.

    Реалізуйте фільтрацію завдань:

    "All" — показує всі

"Active" — тільки невиконані

"Completed" — тільки виконані

Забезпечте мінімізацію перерендерів: при зміні стану одного завдання не повинно перерендерюватися все <ul>, а лише конкретний <li>.
